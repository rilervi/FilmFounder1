# FilmFounder

FilmFounder — це зручний веб-додаток для пошуку фільмів, який дозволяє користувачам швидко знаходити інформацію про улюблені стрічки, переглядати рейтинги, жанри та деталі без потреби реєстрації.

## 🔗 Жива версія: rilervi.github.io/FilmFounder1

🚀 Основні можливості
🔎 Пошук фільмів за назвою через інтерфейс у реальному часі

🎞️ Перегляд описів, жанрів, постерів та рейтингів

🌐 Адаптивний дизайн — зручно на комп’ютерах, планшетах і телефонах

📚 Чистий і мінімалістичний інтерфейс без зайвих елементів

⚡ Швидке завантаження без реєстрацій і встановлення програм

## ⚙️ Технологічний стек
Фронтенд:
React.js — побудова інтерфейсу

HTML/CSS/JavaScript (ES6+) — верстка та логіка

Axios — запити до зовнішнього API

React Router — маршрутизація сторінок

TMDB API — джерело даних про фільми

Інструменти:
Node.js, npm — запуск і менеджмент проєкту

Git + GitHub — контроль версій та співпраця

VS Code — середовище розробки

## Деплоймент:
