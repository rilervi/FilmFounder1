# FilmFounder

FilmFounder — це зручний веб-додаток для пошуку фільмів, який дозволяє користувачам швидко знаходити інформацію про улюблені стрічки, переглядати рейтинги, жанри та деталі без потреби реєстрації.

## 🔗 Жива версія: rilervi.github.io/FilmFounder1

🚀 Основні можливості
🔎 Пошук фільмів за назвою через інтерфейс у реальному часі

🎞️ Перегляд описів, жанрів, постерів та рейтингів

🌐 Адаптивний дизайн — зручно на комп’ютерах, планшетах і телефонах

📚 Чистий і мінімалістичний інтерфейс без зайвих елементів

⚡ Швидке завантаження без реєстрацій і встановлення програм

## ⚙️ Технологічний стек
#### Фронтенд:
React.js — побудова інтерфейсу

HTML/CSS/JavaScript (ES6+) — верстка та логіка

Axios — запити до зовнішнього API

React Router — маршрутизація сторінок

TMDB API — джерело даних про фільми

#### Інструменти:
Node.js, npm — запуск і менеджмент проєкту

Git + GitHub — контроль версій та співпраця

VS Code — середовище розробки

## Деплоймент:
Vercel — для хостингу фронтенду

## 📦 Як запустити проект локально
Щоб запустити FilmFounder на вашому комп’ютері, виконайте наступні кроки:

#### Передумови
Встановлений Node.js (версія 16 або вище)

Менеджер пакетів npm або yarn

Інтернет-з'єднання (для доступу до API фільмів)

▶️ Запуск проєкту
Клонування репозиторію

bash
Копіювати
Редагувати
git clone https://github.com/[Ваш-GitHub]/FilmFounder1.git
cd FilmFounder1
Встановлення залежностей

bash
Копіювати
Редагувати
npm install
Запуск React-додатку

bash
Копіювати
Редагувати
npm start
Після запуску ваш застосунок буде доступний за адресою:
👉 http://localhost:3000
І автоматично відкриється у браузері.

FilmFounder використовує TMDB API або аналогічне API для отримання інформації про фільми. У разі потреби додайте власний API-ключ у відповідний файл конфігурації (наприклад, .env).
